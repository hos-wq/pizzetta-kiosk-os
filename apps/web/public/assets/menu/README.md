# Pizzetta menu assets

Place item PNGs in this folder using the database item id as the filename:

`margherita.png`, `pepperoni.png`, `lasagna-1.png`, `tea-glass.png`, `crust-meal.png`

The frontend can use `/assets/menu/<item-id>.png`. Keep transparent or paper-background artwork consistent with the Pizzetta Brand Vault. Do not add private source files or customer/payment images here; this folder is public web content.
