# PIZZETTA KIOSK — Accessibility Checklist P4

## Implemented

- Checkout fields have visible labels and mobile autocomplete/input modes.
- Quantity controls expose explicit accessible labels.
- Cart and notification controls expose item counts in their labels.
- Product cards are keyboard-openable with Enter/Space.
- Tracking timeline is rendered as text labels, not colour alone.
- Loading and API errors use visible status/alert copy.
- Map link opens in a separate tab with a descriptive label.

## Release checks still required

- VoiceOver pass on iPhone 14 Pro Safari.
- Contrast verification for all category accents.
- Reduced-motion review for future animation work.
- Touch target verification at 44 px minimum on the smallest supported viewport.

P4 becomes `DONE` after these four checks are run and recorded in the release checklist.
